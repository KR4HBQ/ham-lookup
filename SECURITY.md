# Security

Please report security problems privately through
[GitHub's private vulnerability reporting](https://github.com/KR4HBQ/ham-lookup/security/advisories/new),
not in a public issue.

Only the latest version on `main` gets fixes.

Never include your `.env`, passwords or API keys in a report. See
[Security and privacy](README.md#security-and-privacy) for how Ham Lookup handles them.
